# LabPlane 全量品牌迁移实施计划

> 本计划在当前共享工作区原地执行，保留用户现有未提交改动，不创建提交、不重置工作区。

## 1. 建立品牌回归守卫

- 新增品牌扫描测试，覆盖 Go、React、Docker、部署、Chart、脚本及主要文档。
- 先运行测试确认旧标识使其失败，再执行迁移。

## 2. 替换代码与运行标识

- 修改 Go module/import、构建版本注入路径和二进制名称。
- 全量替换环境变量、Cookie、注解域、指标、数据库/KV/cache 前缀。
- 更新日志、用户可见文本和默认资源名称。

## 3. 更新构建与部署资产

- 重命名 Helm Chart 目录与全量部署文件。
- 更新 Dockerfile、Compose、Kubernetes、Helm、CI、脚本及示例命令。
- 检查 RBAC、探针、资源限制与模板渲染结果。

## 4. 完成视觉品牌与登录页

- 生成品牌概念稿并提炼为可维护 SVG。
- 更新站点 Logo、favicon、Apple Touch Icon、PWA 图标与 manifest。
- 改造登录页布局和视觉，保留全部认证逻辑与可访问性。

## 5. 更新文档

- 重写 README 的品牌、定位、命令、镜像、部署与目录说明。
- 更新 AGENTS、示例配置和运维文档中的所有标识。

## 6. 验证与审查

- 运行品牌守卫、格式化、Go test/vet/build、前端构建。
- 运行 Helm/Kubernetes/CI 配置检查。
- 使用临时目录和独立端口启动新二进制，调用存活探针后停止。
- 审查最终差异，确认未覆盖用户无关改动并列出远端仓库改名等外部后续事项。
